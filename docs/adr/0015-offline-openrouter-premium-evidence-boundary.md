## Decision

OpenRouter production access uses a Windows-only bridge and CLI with a fixed Credential Manager target, exactly three authenticated metadata GETs before activation, an opaque account binding, a durable checksum-chained single-writer journal, a DPAPI CurrentUser-sealed single-use authorization, and a fixed raw-free evidence path. The model API id is `openai/gpt-5.6-luna`, canonical release is `openai/gpt-5.6-luna-20260709`, and the selected provider is Azure with ZDR required.

Every paid authority is separately granted and consumed once. The corrected contract permits at most 12 sequential requests, 1,500 microusd per slot, an 18,000-microusd (`$0.018`) aggregate reservation, 15 seconds per credential lease, a 240-second aggregate window, and no retry, fallback, alternate provider, redirect, proxy, cookie, ambient credential, or decompression. The aggregate window covers twelve full leases plus 60 seconds overhead and cannot outlive the authenticated key attestation. The secret is never accepted through argv, environment, configuration, or retained evidence. Any post-dispatch uncertainty remains submission/charge Unknown.

The accepted offline readiness surface is zero-I/O CLI command `plan` and raw-free bounded manifest `snow_globe_openrouter_paid_run_readiness_manifest/v1`, digest `d1e653468fd7a39e33ad355297adf96c48bde97e40a73f6b6c6812623553f737`. `plan` and its invalid-argument closure dispatch before production-factory evaluation. Independent frozen expectations bind `openai/gpt-5.6-luna`, `openai/gpt-5.6-luna-20260709`, Azure/ZDR, twelve one-attempt sequential slots, no retry/alternate, 4,096/512 tokens, minimal excluded reasoning, finish `stop`, 15-second leases, 240-second/key-expiry authority, 1,500/18,000-microusd ceilings, terminal/uncertain stop, and fresh explicit authority.

The manifest inspects all twelve canonical serializer outputs and executes cached fake-only/in-memory conformance through the same evidence executor core used by the production boundary. The registered scripted exchange, fake lease source, in-memory journal, and offline clock observe twelve successes, one-call uncertain stop, a pre-dispatch terminal stop, consumed-capability and duplicate-nonce closure, no retry/alternate, and lease zeroing. These process-local fake capabilities/nonces create no live, durable, paid, account, credential, production-permit, or reusable authority. This conformance does not cover fixed production state-root generation rollover.
